# 真人核心功能测试流程（Human Test Checklist）

> 适用：合并/发布前的最终人工验证。自动化已覆盖 546 项（双版本），本清单覆盖**自动化无法触及的部分**：真实蓝信服务器、真实客户端交互、TTY 向导、端到端体验。
> 预计耗时：P0 冒烟 10 分钟 / P1 全功能 30 分钟 / P2 健壮性按需。
> 环境：OpenClaw 网关（2026.7.1 或 2026.8.1 均可——双版本已自动化验证，人工验证跑其一即可）+ 至少 2 个蓝信账号（1 个机器人主人 + 1 个普通用户）。

---

## 观测工具箱（每步都可能用到）

```bash
# 插件实时日志（连接生死/采纳/巡检/静默退出——全部带 appId）
tail -f /tmp/openclaw/openclaw-$(date +%F).log | grep -E "lansenger|patrol:|gateway:|WS "

# 连接数（应 = 配置的账号数；多出即孤儿连接）
lsof -p $(pgrep -f 'gateway --port 18789' | head -1) -nP | grep ESTABLISHED | grep -v 127.0.0.1

# 真实活性状态（wsAlive/wsState/连接年龄/上次 pong 年龄）
openclaw gateway call lansenger.status   # 或经 dashboard

# 频道健康总览
openclaw status --deep
```

## P0 冒烟（10 分钟，全过才算部署成功）

| # | 操作 | 预期 | 观测点 |
|---|---|---|---|
| 0.1 | 部署插件并 `openclaw gateway restart`，等 30s | 3/3 账号连接（若配 3 账号），日志出现 `gateway: adopting existing healthy WS` 或 `gateway: started`，**无同 key 双 started** | 日志 + 连接数 |
| 0.2 | 主人私聊机器人："你好" | 收到回复；日志有完整链路（inbound → 防抖 → 路由 → deliverReply） | 蓝信客户端 + 日志 |
| 0.3 | 再问："现在几点" | 正常回答（连续对话无异常） | 蓝信客户端 |
| 0.4 | 查巡检快照（等 5 分钟） | 日志出现 `patrol: key=... wsState=OPEN alive=true age=...s lastPongAge=...s`，全部账号 alive=true | 日志 |

**P0 判定**：4 项全过。任何一项失败 → 停止，按日志定位。

## P2 健壮性（按需/定时执行）

| # | 操作 | 预期 | 时限 |
|---|---|---|---|
| 2.1 | **断网 30 秒**再恢复 | 日志：`pong timeout`/`WS closed` → `WS reconnect in Ns` → 重连成功；期间消息在恢复后正常收发 | 恢复后 ≤60s 全通 |
| 2.2 | **网关重启**（`openclaw gateway restart`）×3 次 | 每次连接数回到账号数，**无孤儿累积**；日志出现采纳（adopting）而非双拨号 | 每次 ≤30s |
| 2.3 | **改错密钥**重启 | 该账号**显性报错**（`getAppToken: errCode=40018` + `channel exited` 持续可见），其他账号不受影响；改回后自愈 | — |
| 2.4 | **服务端视角验证**（若有服务端日志权限）：用户发消息收到"机器人长连接异常断开"的时刻，对照插件日志 | 插件侧必有对应断连/重连日志（不再有静默假死） | — |
| 2.5 | **24-72h 挂机**（长稳） | 连接数恒定；`patrol:` 快照全绿；无 dead WS 自愈事件；机器人全程响应；用户零"长连接异常断开"投诉 | 每日巡检一次 |

## 通过标准

- **P0 全过** + **P1 全过** → 可合并发布
- P2.1-P2.3 建议合并前做一轮；P2.5 发布后持续观察 72h
- 任何失败：先查观测工具箱输出定位（所有高危路径都有日志），必要时对照 `docs/zombie-lifecycle-postmortem.md` 的排障手册

## 已知边界（不是缺陷）

- 服务端票据缓存 110min：密钥失效后 WS 最长还能连 110 分钟（服务端行为，插件已显性报错 token 失败）
- 服务端 Redis 会话 24h TTL 不随 ping 续期：插件以 12h 连接轮换对冲
- 断连期间的消息不补发（服务端 STOP_IGNORE 语义）
